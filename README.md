# 🧠 Voluntariado Inteligente

Sistema completo para gerenciamento de voluntários e instituições.

## 🚀 Funcionalidades
- Login
- Cadastro de voluntários
- Agenda com mapa
- Recompensas e ranking

## 🛠️ Tecnologias
- Flutter
- Angular
- Spring Boot
- PostgreSQL

## ⚙️ Como rodar
### Backend
cd backend
mvn spring-boot:run

### Flutter
flutter pub get
flutter run
